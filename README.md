# Check-Innon

Скрипт следит за двумя тарифами на [my.innon.org](https://my.innon.org) и присылает уведомление в Telegram, когда тариф становится доступен для покупки. Каждый тариф можно включать и выключать отдельно.

| Тариф | Страница | Цена |
|---|---|---|
| **LC-B1** (EPYC 9275F) | https://my.innon.org/epyc-9275f | 399 ₽ |
| **LC-A1** (Ultra 7 265) | https://my.innon.org/ultra7-265 | 299 ₽ |

Используется только стандартная библиотека Python 3.8+, ничего устанавливать через pip не нужно.

## Как это работает

Каждый тариф на странице - отдельная карточка. У недоступного тарифа в ней стоит надпись «Нет в наличии», у доступного - кнопка «Добавить в корзину». Скрипт раз в 10-13 секунд скачивает каждую страницу, находит карточки по названию и смотрит, какая из надписей в них есть.

- Когда тариф появляется, приходит **одно** сообщение с названием и ценой. Повторов нет. Следующее придёт, только если тариф сначала пропадёт, а потом появится снова.
- Когда тариф раскупили, приходит одно сообщение «снова раскупили».
- Когда ты включаешь или выключаешь тариф в меню, приходит сообщение «Начал следить» или «Перестал следить».
- Если тариф не найден на странице (изменилась вёрстка или сайт отдал антибот-заглушку), приходит предупреждение.
- Если страница не открывается 10 раз подряд, тоже приходит предупреждение.

Если тариф уже в наличии в момент запуска или включения, уведомление придёт сразу.

Скрипт только уведомляет. Покупать нужно вручную, поэтому заранее залогинься на сайте и пополни баланс.

## Как устроено внутри

Скрипт работает в трёх независимых потоках, поэтому медленный Telegram не тормозит проверку сайта:

- **проверка** качает страницы раз в 10-13 секунд и разбирает тарифы;
- **опрос** читает сообщения, написанные боту, и готовит ответы-статусы;
- **отправка** берёт сообщения из очереди и отправляет их с повторами (до 10 попыток по 10 секунд).

Если ответ сайта или Telegram дольше 5 секунд, об этом пишется строка в лог (`innon logs`).

## Статус по запросу

Напиши своему боту любое сообщение (например `/status` или просто «?»), и он ответит статусом. Так можно проверить, что мониторинг вообще жив:

```
✅ Check-Innon v1.3.1 работает
Аптайм: 3д 2ч 5м
Последняя проверка: 4с назад (проверяю каждые ~10 с)

Слежу за:
• LC-B1: 399.00₽, нет в наличии
• LC-A1: 299.00₽, ДОСТУПЕН 🔥
```

В статусе только то, что включено (выключенные тарифы не показываются). Видно версию, сколько скрипт работает, как давно была последняя проверка, за какими тарифами он следит и что с ними сейчас. Если «последняя проверка» заметно старше ~13 секунд, смотри логи: `innon logs`. Если страница не открывается или тариф не найден, это тоже будет написано.

Бот отвечает только тому, чей ID указан в `TG_CHAT_ID`, остальным он не отвечает. Сообщения, написанные боту, пока он был выключен, игнорируются. Чтобы статус работал, скрипт должен быть единственным, кто читает сообщения бота: не запускай параллельно второй экземпляр и не настраивай webhook для того же бота.

## Настройка Telegram

1. Напиши [@BotFather](https://t.me/BotFather), выполни `/newbot` и получи токен (`TG_TOKEN`).
2. Напиши своему новому боту `/start`. Без этого бот не сможет писать тебе первым.
3. Узнай свой числовой ID (`TG_CHAT_ID`) одним из способов:
   - напиши боту [@userinfobot](https://t.me/userinfobot);
   - открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":...}`.

Для личной переписки `chat_id` равен твоему user ID. Если указать ID группы, уведомления придут в группу.

## Установка на Debian 13 одной командой

Зайди на сервер по SSH под root и выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh | bash
```

Если `curl` не установлен: `apt update && apt install -y curl`.

Установщик сам:
1. ставит `python3`, `git`, `curl`, `ca-certificates`;
2. создаёт системного пользователя `monitor` без прав входа;
3. клонирует репозиторий в `/opt/innon-monitor`;
4. создаёт список тарифов `watches.conf` (LC-B1 и LC-A1, оба включены);
5. спрашивает `TG_TOKEN` и `TG_CHAT_ID` (ввод виден) и сохраняет их в `/opt/innon-monitor/.env` (права 640);
6. проверяет токен запросом к Telegram;
7. включает службу `innon-monitor` с автозапуском и перезапуском при падении;
8. ставит команду `innon` - меню управления.

В конце в Telegram приходит сообщение «Мониторинг запущен» с версией. Напиши боту что угодно, и он ответит статусом.

Токен и ID можно передать заранее, тогда вопросов не будет:

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh -o install.sh
TG_TOKEN="123456:ABC-твой-токен" TG_CHAT_ID="123456789" bash install.sh
```

### Меню управления

После установки просто введи:

```bash
innon
```

```
Check-Innon v1.3.1 (627d469)   мониторинг: РАБОТАЕТ
Тарифы (номер - включить/выключить):
  1) LC-B1  [ВКЛ  ] EPYC 9275F, 399 ₽
  2) LC-A1  [выкл ] Ultra 7 265, 299 ₽
Другое:
  3) Логи
  4) Токен бота и ID получателя
  5) Обновить из GitHub
  6) Удалить всё (бот, служба, скрипты)
  0) Выход
Выбор:
```

**Логи.** Последние 40 строк и по желанию живой вывод (выход из него: Ctrl+C).

**Токен.** Новые данные сначала проверяются тестовым сообщением в Telegram и сохраняются, только если оно дошло, так что опечатка не сломает работающего бота.

**Тарифы.** Номер тарифа переключает его: был включён - выключится, был выключен - включится. Отдельно включать и выключать службу не нужно: пока включён хотя бы один тариф, мониторинг работает, когда выключены все - останавливается сам. Изменение применяется без перезапуска, в течение ~15 секунд.

**Навигация.** Пункт выбирается одной клавишей, Enter не нужен. Из любого вопроса можно выйти: `0` или пустой Enter возвращают в меню. Выход из самого меню - `0`. После действия меню сразу показывается снова с обновлённым состоянием, поэтому отдельного пункта «Статус» нет: текущее состояние всегда в шапке и в списке тарифов (а подробный статус бот пришлёт в Telegram).

**Удалить всё** после подтверждения словом `yes` удаляет службу, папку `/opt/innon-monitor` (скрипты, токены, список тарифов), пользователя `monitor` и саму команду `innon`. Пакеты `python3`, `git` и `curl` остаются.

Версия скрипта и короткий хэш коммита показаны в шапке меню. Узнать версию можно и командой `innon version`.

То же без меню: `innon version`, `innon status`, `innon on 1`, `innon off 2`, `innon token`, `innon test`, `innon logs`, `innon update`, `innon uninstall`. Номера тарифов те же, что в меню.

### Всё лежит в одном месте

```
/opt/innon-monitor/
├── monitor.py              # сам мониторинг
├── VERSION                 # номер версии
├── manage.sh               # меню (команда innon - симлинк на него)
├── install.sh              # установка / обновление / удаление
├── innon-monitor.service   # подключается к systemd симлинком
├── watches.conf            # список тарифов (в git не попадает)
├── .env                    # токены (в git не попадает)
└── .git/
```

`watches.conf` - обычный текстовый файл, по строке `URL|ТАРИФ`. Выключенный тариф помечен `|off`:

```
https://my.innon.org/epyc-9275f|LC-B1
https://my.innon.org/ultra7-265|LC-A1|off
```

Файл можно править и руками, мониторинг перечитывает его на каждом круге.

### Обновление

Пункт «Обновить из GitHub» в меню или та же команда установки ещё раз. После обновления из меню оно автоматически открывается заново уже новой версией. Код подтянется через `git pull`, `.env` и `watches.conf` останутся нетронутыми. Если мониторинг был выключен, обновление его не включит. Если установщик сам обновился, он автоматически продолжает работу новой версией. Недостающие тарифы LC-B1 и LC-A1 дописываются в `watches.conf` (включёнными), существующие строки и выключенные тарифы не меняются.

### Удаление без меню

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh | bash -s -- --uninstall
```

## Запуск вручную (без установки)

```bash
export TG_TOKEN="123456:ABC-твой-токен"
export TG_CHAT_ID="123456789"
python3 monitor.py                       # слежение по watches.conf
python3 monitor.py --test-telegram       # тестовое сообщение
python3 monitor.py --version             # версия
```

Если `watches.conf` нет, отслеживается только LC-B1 на странице EPYC 9275F.

## Настройки в скрипте

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `CHECK_EVERY` | `10` | Пауза между кругами проверки, секунд (плюс 0-3 с случайно) |
| `FAILS_BEFORE_ALERT` | `10` | Сколько ошибок подряд по странице до предупреждения |
| `WATCHES_FILE` | `watches.conf` рядом со скриптом | Переменная окружения, путь к списку тарифов |

После правки `monitor.py` выполни `systemctl restart innon-monitor`. Учти, что ручные правки в `monitor.py` могут помешать обновлению через `git pull` (он откажется обновляться при конфликте), поэтому постоянные изменения лучше вносить через форк репозитория.

## Замечания

- Если сервер с мониторингом находится в России, Telegram может не открываться. Используй VPS в Европе или настрой прокси.
- Слишком частые запросы (`CHECK_EVERY` меньше 5 секунд) могут привести к блокировке по IP.
- Токен бота не коммить в репозиторий: файлы `.env` и `watches.conf` добавлены в `.gitignore`.
- Разметка разобрана по сохранённым страницам сайта. Если сайт отдаёт анонимным пользователям другую страницу, скрипт напишет, что тариф не найден.
