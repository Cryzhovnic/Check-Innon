# Check-Innon

Скрипт следит за тарифами на [my.innon.org](https://my.innon.org) и присылает уведомление в Telegram, когда тариф становится доступен для покупки. Тарифов и страниц можно отслеживать сколько угодно. По умолчанию:

| Тариф | Страница | Цена |
|---|---|---|
| **LC-B1** (EPYC 9275F) | https://my.innon.org/epyc-9275f | 399 ₽ |
| **LC-A1** (Ultra 7 265) | https://my.innon.org/ultra7-265 | 299 ₽ |

Используется только стандартная библиотека Python 3.8+, ничего устанавливать через pip не нужно.

## Как это работает

Каждый тариф на странице - отдельная карточка. У недоступного тарифа в ней стоит надпись «Нет в наличии», у доступного - кнопка «Добавить в корзину». Скрипт раз в 10-13 секунд скачивает каждую страницу (по одному разу, даже если на ней несколько отслеживаемых тарифов), находит карточки по названию и смотрит, какая из надписей в них есть.

- При появлении тарифа приходит сообщение с названием и ценой, дальше оно повторяется раз в минуту, пока тариф доступен.
- Если тариф снова раскупили, приходит отдельное сообщение.
- Если тариф не найден на странице (изменилась вёрстка, тариф убрали или сайт отдал антибот-заглушку), приходит предупреждение.
- Если страница не открывается 10 раз подряд, тоже приходит предупреждение.

Если тариф уже в наличии в момент запуска, уведомление придёт сразу.

Скрипт только уведомляет. Покупать нужно вручную, поэтому заранее залогинься на сайте и пополни баланс.

## Настройка Telegram

1. Напиши [@BotFather](https://t.me/BotFather), выполни `/newbot` и получи токен (`TG_TOKEN`).
2. Напиши своему новому боту `/start`. Без этого бот не сможет писать тебе первым.
3. Узнай свой числовой ID (`TG_CHAT_ID`) одним из способов:
   - напиши боту [@userinfobot](https://t.me/userinfobot);
   - открой `https://api.telegram.org/bot<ТОКЕН>/getUpdates` и найди `"chat":{"id":...}`.

Для личной переписки `chat_id` равен твоему user ID. Если указать ID группы, уведомления придут в группу.

## Установка на Debian 13 одной командой

Зайди на сервер по SSH под root и выполни:

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh | bash
```

Если `curl` не установлен: `apt update && apt install -y curl`.

Установщик сам:
1. ставит `python3`, `git`, `curl`, `ca-certificates`;
2. создаёт системного пользователя `monitor` без прав входа;
3. клонирует репозиторий в `/opt/innon-monitor`;
4. создаёт список тарифов `watches.conf` (LC-B1 и LC-A1);
5. спрашивает `TG_TOKEN` и `TG_CHAT_ID` и сохраняет их в `/opt/innon-monitor/.env` (права 640);
6. проверяет токен запросом к Telegram;
7. включает службу `innon-monitor` с автозапуском и перезапуском при падении;
8. ставит команду `innon` - меню управления.

В конце в Telegram приходит сообщение «Мониторинг запущен».

Токен и ID можно передать заранее, тогда вопросов не будет:

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh -o install.sh
TG_TOKEN="123456:ABC-твой-токен" TG_CHAT_ID="123456789" bash install.sh
```

### Меню управления

После установки просто введи:

```bash
innon
```

```
Check-Innon   мониторинг: РАБОТАЕТ   тарифов: 2
  1) Статус
  2) Включить мониторинг
  3) Выключить мониторинг
  4) Перезапустить
  5) Добавить тариф для слежения
  6) Убрать тариф из слежения
  7) Сменить токен бота / ID получателя
  8) Отправить тестовое сообщение в Telegram
  9) Показать логи
 10) Обновить из GitHub
 11) Удалить всё (бот, служба, скрипты)
  0) Выход
```

Пункты можно вызывать и без меню: `innon status`, `innon start`, `innon stop`, `innon restart`, `innon list`, `innon add`, `innon remove`, `innon token`, `innon test`, `innon logs`, `innon update`, `innon uninstall`.

**Добавить тариф (пункт 5).** Вставь ссылку на страницу с тарифами, например `https://my.innon.org/ultra7-265`. Меню загрузит страницу, покажет все тарифы на ней с ценой и текущим статусом, и ты выберешь номера для слежения (или `a` для всех). Так можно добавить любую другую страницу.

**Выключить мониторинг (пункт 3)** останавливает службу и убирает её из автозапуска. Обновление при этом выключенный мониторинг не включает.

**Удалить всё (пункт 11)** после подтверждения словом `yes` удаляет службу, папку `/opt/innon-monitor` (скрипты, токены, список тарифов), пользователя `monitor` и саму команду `innon`. Пакеты `python3`, `git` и `curl` остаются.

### Всё лежит в одном месте

```
/opt/innon-monitor/
├── monitor.py              # сам мониторинг
├── manage.sh               # меню (команда innon - симлинк на него)
├── install.sh              # установка / обновление / удаление
├── innon-monitor.service   # подключается к systemd симлинком
├── watches.conf            # список тарифов (в git не попадает)
├── .env                    # токены (в git не попадает)
└── .git/
```

Список тарифов - обычный текстовый файл, по строке `URL|ТАРИФ`. Его можно править и руками, после этого выполни `innon restart`:

```
https://my.innon.org/epyc-9275f|LC-B1
https://my.innon.org/ultra7-265|LC-A1
```

### Обновление

Пункт 10 в меню или та же команда установки ещё раз. Код подтянется через `git pull`, `.env` и `watches.conf` останутся нетронутыми.

### Удаление без меню

```bash
curl -fsSL https://raw.githubusercontent.com/Cryzhovnic/Check-Innon/main/install.sh | bash -s -- --uninstall
```

## Запуск вручную (без установки)

```bash
export TG_TOKEN="123456:ABC-твой-токен"
export TG_CHAT_ID="123456789"
python3 monitor.py                       # слежение по watches.conf
python3 monitor.py --list https://my.innon.org/ultra7-265   # тарифы на странице
python3 monitor.py --test-telegram       # тестовое сообщение
```

Если `watches.conf` нет, отслеживается только LC-B1 на странице EPYC 9275F.

## Настройки в скрипте

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `CHECK_EVERY` | `10` | Пауза между кругами проверки, секунд (плюс 0-3 с случайно) |
| `REMIND_EVERY` | `60` | Как часто повторять уведомление, пока тариф доступен |
| `FAILS_BEFORE_ALERT` | `10` | Сколько ошибок подряд по странице до предупреждения |
| `WATCHES_FILE` | `watches.conf` рядом со скриптом | Переменная окружения, путь к списку тарифов |

После правки `monitor.py` выполни `innon restart`. Учти, что ручные правки в `monitor.py` могут помешать обновлению через `git pull` (он откажется обновляться при конфликте), поэтому постоянные изменения лучше вносить через форк репозитория.

## Замечания

- Если сервер с мониторингом находится в России, Telegram может не открываться. Используй VPS в Европе или настрой прокси.
- Слишком частые запросы (`CHECK_EVERY` меньше 5 секунд, много страниц) могут привести к блокировке по IP.
- Токен бота не коммить в репозиторий: файлы `.env` и `watches.conf` добавлены в `.gitignore`.
- Разметка разобрана по сохранённым страницам сайта. Если сайт отдаёт анонимным пользователям другую страницу, скрипт напишет, что тариф не найден.
- Если список тарифов пуст, служба не перезапускается в цикле, а просто останавливается. Добавь тариф в меню и включи мониторинг.
